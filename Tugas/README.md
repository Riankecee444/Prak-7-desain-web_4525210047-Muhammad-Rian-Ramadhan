# Form Pendaftaran Mahasiswa

## Deskripsi
Proyek ini merupakan prototype form pendaftaran mahasiswa berbasis website menggunakan HTML, CSS, dan JavaScript.

## Fitur
- Input nama lengkap
- Input email
- Input password
- Input tanggal lahir
- Input nilai
- Pilihan jurusan
- Tombol Daftar
- Tombol Reset
- Tombol Hapus Hasil

## Teknologi
- HTML untuk membuat struktur form
- CSS untuk mengatur tampilan website
- JavaScript untuk mengatur interaksi form

## Struktur Folder
Tugas/
- index.html
- style.css
- README.md

## Cara Menjalankan
1. Buka folder proyek di Visual Studio Code.
2. Buka file index.html.
3. Jalankan menggunakan Live Server atau browser.
4. Isi data pendaftaran.
5. Klik tombol Daftar untuk menampilkan hasil.

## Responsif
Website dirancang agar dapat dibuka melalui desktop dan perangkat mobile.

## Catatan
Proyek ini masih berupa prototype frontend dan belum menggunakan database.
